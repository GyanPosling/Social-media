# API Gateway

`apigateway` is the public entry point for the system. It validates JWT tokens, adds trusted user headers, signs internal requests, and routes traffic to backend services.

## Responsibilities

- Route `/auth/**` to `authservice` with Redis-backed rate limiting.
- Route `/users/**` to `userservice`.
- Route `/posts/**` to `postservice`.
- Route `/notifications/**` to `notificationservice`.
- Skip authentication for login, registration, actuator health/info, and OpenAPI paths.
- Validate bearer tokens for protected routes.
- Add gateway-owned headers for downstream services.
- Apply retry and circuit breaker filters for selected routes.
- Generate and forward `X-Correlation-Id`.

## Runtime

| Property | Value |
| --- | --- |
| Port | `8080` |
| Framework | Spring Cloud Gateway WebFlux |
| Cache dependency | Redis |
| Security | JWT resource server + HMAC downstream signing |
| Rate limiting | Redis-backed `RequestRateLimiter` on `/auth/**` |

## Routes

| Route id | Path | Default target |
| --- | --- | --- |
| `authservice` | `/auth/**` | `http://localhost:8083` |
| `userservice` | `/users/**` | `http://localhost:8081` |
| `postservice` | `/posts/**` | `http://localhost:8082` |
| `notificationservice` | `/notifications/**` | `http://localhost:8084` |

## Forwarded Headers

| Header | Description |
| --- | --- |
| `X-User-Id` | JWT subject parsed as UUID |
| `X-User-Email` | Email claim from JWT, when present |
| `X-TS` | Request timestamp in epoch seconds |
| `X-SIGN` | HMAC-SHA256 signature for downstream validation |
| `X-Correlation-Id` | Request correlation id generated by the gateway when missing |

The signature payload is:

```text
METHOD|PATH|USER_ID|EMAIL|TIMESTAMP
```

## Configuration

| Variable | Default |
| --- | --- |
| `JWT_SECRET` | `change-this-secret-to-at-least-32-characters` |
| `GATEWAY_INTERNAL_SIGNING_SECRET` | `change-this-internal-secret-to-at-least-32-characters` |
| `AUTHSERVICE_BASE_URL` | `http://localhost:8083` |
| `USERSERVICE_BASE_URL` | `http://localhost:8081` |
| `POSTSERVICE_BASE_URL` | `http://localhost:8082` |
| `NOTIFICATIONSERVICE_BASE_URL` | `http://localhost:8084` |
| `CORS_ALLOWED_ORIGINS` | `http://localhost:3000,http://localhost:5173` |
| `AUTH_RATE_LIMIT_REPLENISH_RATE` | `5` |
| `AUTH_RATE_LIMIT_BURST_CAPACITY` | `10` |

## Local Run

```powershell
.\gradlew.bat :apigateway:bootRun
```

Health endpoint:

```text
GET http://localhost:8080/actuator/health
```

Run tests:

```powershell
.\gradlew.bat :apigateway:test
```
